# 💰進度（Jin Du Progress）

個人財務管理 Flutter MVP，採 iPhone 優先的跨平台架構，未來可支援 Android。

## 第一版包含
- 財務總覽：本月已入帳收入、支出、待入帳佣金、現金、總負債
- 收支紀錄：新增收入／支出、分類、待入帳狀態、長按刪除
- 債務管理：信貸／學貸本金、利率、月付款與備註可編輯
- 存款目標：新增目標、存入金額、進度條
- 財務分析：累計收入、支出、收支差額與負債
- 本機資料保存：使用 shared_preferences 儲存 JSON

## 執行方式
需先安裝 Flutter SDK 與 Xcode（iOS 編譯需 macOS）。

```bash
flutter pub get
flutter run
```

建立 iOS 專案平台檔（若尚未建立）：
```bash
flutter create . --platforms=ios,android
```

## 重要說明／目前限制
1. 這是可供 Flutter 開發環境執行的 MVP 原始碼，不是已簽署、編譯或上架的 iOS App。
2. 本機資料目前以 shared_preferences 儲存，尚未加密；正式上線前應改用加密 SQLite／安全金鑰管理，並完成隱私與資安檢測。
3. 尚未連接銀行、信用卡或保險公司系統；不會自動同步帳戶餘額或代扣款。
4. 雲端備份、Face ID、推播提醒、正式 CSV/Excel 匯出、完整 12 個月現金流預測，列為第二階段。
5. 記帳會同步調整目前現金餘額；刪除交易目前不會自動回沖現金，正式版需加入完整的交易更正／沖銷流程。
6. 目標存入會從目前現金扣除；若只是把同一帳戶內的錢轉入儲蓄子帳戶，正式版應以「帳戶間轉帳」處理，避免誤算總資產。
7. 信貸與學貸實際利率、期數與月付，請以銀行最新帳單為準。App 內數值可自行修改。
