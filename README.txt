💰進度 PWA 網頁版

部署方式（免費）：
1. 使用 GitHub 帳號登入 https://github.com
2. 建立 Public repository，名稱例如 jindu-progress
3. 將本資料夾內所有檔案上傳到 repository 根目錄
4. Settings > Pages > Deploy from a branch > main > /(root) > Save
5. 等待 GitHub Pages 顯示網址，格式 https://你的帳號.github.io/jindu-progress/
6. iPhone 用 Safari 開啟網址 > 分享 > 加入主畫面

資料儲存在該 iPhone Safari 的 localStorage。清除網站資料或更換手機可能導致資料遺失，請定期備份。此 MVP 尚無帳號登入或雲端同步。
